Installation on Windows PowerShell

The commands below follow the supplied README. Replace the sample path with the actual folder on your machine.

# 1. Move to the project folder
cd "D:\path\to\orthopedic_clinic"

# 2. Create a virtual environment
python -m venv .venv

# 3. Activate it
.\.venv\Scripts\Activate.ps1

# 4. Install dependencies
python -m pip install --upgrade pip
pip install -r requirements.txt

# 5. Create local environment settings
Copy-Item .env.example .env
notepad .env

Run the application

# Easiest documented option: double-click run.bat

# Or run from PowerShell
.\.venv\Scripts\python.exe run.py
Default credentials in the README

The supplied file lists a default admin login and explicitly says to change it immediately after first login. Do not keep default credentials in a real deployment.

Environment configuration

# Local database
DATABASE_URL=sqlite:///clinic.db

# AI provider (optional)
AI_API_KEY=your_key_here
AI_MODEL=your_model_name
AI_BASE_URL=https://api.groq.com/openai/v1

# Logging
LOG_LEVEL=INFO

Use placeholder values in shared documentation. Never put a real API key into this public showcase or commit it to version control.

Developer workflow

Code conventions

The README recommends PEP 8, type hints, docstrings for important utilities, small functions, and meaningful names.

Tests

Run the test suite with .\.venv\Scripts\pytest from the project environment.

Adding a feature

Consider the model, repository, service, UI page, navigation registration, and Arabic/English translations in the documented order.

Troubleshooting

Check logs/app.log, confirm dependencies are installed, verify AI configuration, and maintain a recent backup of the database and patient files.
