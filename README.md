# OrthoCare Showcase

A responsive, bilingual website presenting the Orthopedic Clinic Management System desktop application.

## Pages
- `index.html` — project overview, download button, supervisor banner, and team preview
- `pages/team.html` — supervisor and team credits
- `pages/features.html` — application features
- `pages/gallery.html` — application screenshots
- `pages/architecture.html` — application structure and AI request flow
- `pages/ai-assistant.html` — AI assistant workflow and limits
- `pages/database.html` — database and security overview
- `pages/technical-guide.html` — setup and developer information

## Download the desktop app
The website download buttons link to the installer in the [ERP Clinic System repository](https://github.com/sa1dek/erp-clinic-system).

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Screenshots
The gallery images are illustrative screenshots with sample interface data. Do not publish real patient data.

## Technology
HTML5, CSS3, and vanilla JavaScript. The website is a project showcase and does not connect to the desktop application's local database.
